# Guess Number

Jogo web em que a pessoa tenta descobrir um número aleatório entre 0 e 10. Projeto de estudo com HTML, CSS e JavaScript.

## Stack
- HTML, CSS e JavaScript

## Como executar
Abra `index.html` no navegador. Também é possível executar com Docker:

```bash
docker build -t guess-number .
docker run --rm -p 8080:80 guess-number
```
